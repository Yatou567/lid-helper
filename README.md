# 合盖助手 · Lid Helper

macOS 菜单栏小工具，一键切换「合盖保持运行」与「恢复正常睡眠」，用于尝试合盖远程办公。

## 下载和使用

**[下载最新版本](https://github.com/Yatou567/lid-helper/releases/latest)**

从本仓库的 **Releases** 下载 `LidHelper-v1.0.0-macos-arm64.zip`，解压后双击「合盖助手.app」。点击菜单栏「合盖」，即可打开控制面板并切换状态。系统会在修改电源设置时请求管理员验证。

当前安装包适用于 **Apple M 系列芯片、macOS 14 或以上**。Intel Mac 和 Windows 不适用。

应用采用临时签名，未经过 Apple 公证。开启后，首次使用请在电脑旁拔掉电源并合盖，通过另一台设备确认远程连接、画面和输入正常，再用于远程办公。系统开关改变不代表已经完成合盖兼容性验证。

## 功能

- 读取真实系统状态，切换前后再次核实。
- 使用系统管理员验证，不保存密码。
- 可取消验证；授权失败或状态不符时显示错误。
- 对电池供电和插电供电同时生效。
- 无网络请求，无开机启动项，无常驻特权服务，不修改 sudoers。

**退出工具不会恢复睡眠。办公结束后，请点击「恢复正常睡眠」。** 开启期间会增加耗电，请保持通风。

## 工作原理

仅修改系统全局 `SleepDisabled` 设置，两个固定命令分别是：

```sh
# 合盖保持运行
sudo pmset -a disablesleep 1

# 恢复正常睡眠
sudo pmset -a disablesleep 0
```

关闭开关只是重新允许系统睡眠，不会立即让电脑睡眠，也不会修改其他睡眠计时设置。

## 构建

需要安装 Xcode 或 Command Line Tools，在源码目录运行：

```sh
zsh build.sh
```

应用生成在源码目录的上一级。构建还会运行逻辑测试并读取真实系统状态，不会修改电源设置。

## 验证范围

已完成本机编译、临时签名校验、真实电源状态读取，以及状态解析、双向切换、取消授权、授权失败和状态核实失败的逻辑测试。图形界面、真实管理员授权与合盖远程连接尚未完成实测。
