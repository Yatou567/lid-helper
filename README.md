# 合盖助手 · Lid Helper

macOS 菜单栏小工具，一键切换「合盖保持运行」与「恢复正常睡眠」，用于尝试合盖远程办公。

## 下载和使用

**[下载最新版本](https://github.com/Yatou567/lid-helper/releases/latest)**

从本仓库的 **Releases** 下载 `LidHelper-v1.1.0-macos-arm64.zip`，解压后双击「合盖助手.app」。点击菜单栏「合盖」，即可打开控制面板并切换状态。开启时系统会请求管理员验证，随后在本次运行期间自动维持，无需为每次恢复重复验证。

当前安装包适用于 **Apple M 系列芯片、macOS 14 或以上**。Intel Mac 和 Windows 不适用。

应用采用临时签名，未经过 Apple 公证。开启后，首次使用请在电脑旁拔掉电源并合盖，通过另一台设备确认远程连接、画面和输入正常，再用于远程办公。系统开关改变不代表已经完成合盖兼容性验证。

## 功能

- 读取真实系统状态，切换前后再次核实。
- 开启后每 2 秒核实 `SleepDisabled`，被系统或其他工具改回时自动重新开启；持续插电时也会检查。
- 监听电源切换与唤醒，并区分“系统状态”与“自动维持”；进程中断或状态异常会明确提示。
- 恢复正常睡眠时先停止自动维持，再明确写入关闭值，避免误反转或关闭后又被重新开启。
- 使用系统管理员验证，不保存密码。
- 可取消验证；授权失败或状态不符时显示错误。
- 对电池供电和插电供电同时生效。
- 无网络请求，无开机启动项，不安装系统服务，不修改 sudoers。开启后有一个临时授权后台进程；恢复或退出后停止。

**退出工具会停止自动维持，但保留系统开关当前值。办公结束后，请先点击「恢复正常睡眠」。** 开启期间会增加耗电，请保持通风。

## 工作原理

仅修改系统全局 `SleepDisabled` 设置，两个固定命令分别是：

```sh
# 合盖保持运行
sudo pmset -a disablesleep 1

# 恢复正常睡眠
sudo pmset -a disablesleep 0
```

开启时通过系统授权运行固定的临时监测脚本，只调用系统自带命令。它绑定本次应用进程的 PID、启动时间及随机会话目录，不执行用户可编辑的脚本文件。检测到设置为 `0` 时，重新写入 `1`；无法读取状态多次或写入失败时退出，并由界面提示中断。

停止请求优先于重新开启；确认监测进程退出、实际状态为 `0` 后，才显示恢复成功。退出应用只停止监测，沿用旧版保留开关值的行为。进程意外退出后也停止监测，不会在重启后自动恢复。

应用同时持有系统防空闲睡眠断言，降低检查间隙因空闲进入睡眠的机会。该断言不能保证阻止合盖强制睡眠。2 秒检查也不能消除所有时间窗口，低电量、过热或系统强制睡眠仍可能导致远程中断。首次请在目标电脑旁验证。[Apple 对普通空闲睡眠与合盖强制睡眠的说明](https://developer.apple.com/library/archive/qa/qa1340/_index.html)。

关闭开关只是重新允许系统睡眠，不会立即让电脑睡眠，也不会修改其他睡眠计时设置。

## 构建

需要安装 Xcode 或 Command Line Tools，在源码目录运行：

```sh
zsh build.sh
```

应用生成在源码目录的上一级。构建还会运行逻辑测试并读取真实系统状态，不会修改电源设置。

## 验证范围

v1.1.0 已完成本机编译、临时签名校验、真实电源状态读取、授权脚本语法编译，以及状态解析、明确关闭、取消授权、错误与中断的逻辑测试。

回归测试运行真实监测脚本并替换为模拟 `pmset`：验证反复被改回后恢复、关闭与重置同时发生、关闭后不再重开、退出与所属进程结束后停止监测。这些测试不会修改本机电源设置。

真实管理员授权、长时间插电和合盖远程连接仍需在目标电脑上实测。
